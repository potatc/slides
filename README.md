# Potatc Slides

### Your ideas. Your canvas.

**A free, open-source workspace for creating, editing and presenting slides.**

`Windows & Web` · `English & Chinese UI` · `MIT Open Source`

[Open in your browser](https://slides.potatc.org/) · [Download for Windows](https://github.com/potatc/slides/releases/tag/EXE1.0) 

---

Potatc Slides brings a freeform slide editor and presentation player into one workspace. Arrange text, shapes, media and data on a canvas, then give your story a rhythm with animations and interactive content.

The aim is simple: **see your content, shape your ideas and take your work with you.**

## Design philosophy

### 01 — Start with less setup

Open the web app or use the Windows desktop application. Creating, editing and presenting belong in the same workflow, so you can spend more time on your ideas.

### 02 — Think directly on the canvas

Text, shapes, images, charts and code share a common workspace. Move, resize, rotate and align objects directly. Contextual controls keep relevant actions close to the content you are working on.

### 03 — Make room for the web

Presentations can include playable media, embedded websites and interactive content. Combine them with charts, tables and code to explain ideas in the format that suits them best.

### 04 — Keep your work usable

Save editable projects and return to them later. Backward compatibility, recovery drafts and reusable media assets support a workflow that continues beyond a single editing session.

**Your presentation should remain yours to edit, present and share.**

## Features

| Feature | What you can do |
| :--- | :--- |
| **Freeform editing** | Build slides with text, shapes and images. Move, resize, rotate and align objects, with multi-selection, grouping and layer controls. |
| **Animation tools** | Arrange entrances, adjust timing and triggers, and preview how your content appears. |
| **Charts and data** | Turn numbers into bar, line and pie charts. Combine charts with editable data tables to explain comparisons and trends. |
| **Media and web embeds** | Add video, audio and embedded webpages to your presentation. |
| **Code blocks** | Present syntax-highlighted code alongside diagrams, text and other content. |
| **Presenter tools** | Use speaker notes, timers, a laser pointer and drawing tools while presenting. |
| **Saving and sharing** | Save editable projects, export a standalone HTML presentation player, or use the print / PDF workflow. |
| **Mobile and touch** | Work with a responsive interface, slide navigation and touch-friendly editing controls. |
| **Editing essentials** | Undo and redo, recovery drafts, reusable media assets, and English and Chinese interface options. |

## From an idea to a presentation

### Build your story

Start with a blank slide or explore the welcome presentation. Add content, arrange it on the canvas and refine the relationships between your ideas.

### Set the pace

Use animations to reveal information when it matters. Let objects appear together, introduce them in sequence or wait for a click before continuing.

### Bring the details to life

Use a chart for a comparison, a code block for an implementation detail or a video for a demonstration. Embedded webpages can bring supported web content into the presentation itself.

### Take the stage

Preview your work, open the presenter tools and deliver your story. Save an editable project for future changes or export a presentation player for sharing.

## Get started

Choose how you want to use Potatc Slides:

| Platform | Start here |
| :--- | :--- |
| **Web app** | [Open slides.potatc.org](https://slides.potatc.org/) and start in your browser. |
| **Windows application** | [Download the Windows EXE](https://github.com/potatc/slides/releases/tag/EXE1.0) from the GitHub release page. |

1. Open Potatc Slides using either option above.
2. Explore the welcome deck, or choose **File → New** to create a presentation. On a phone, open **More** to reach the file options.
3. Add content through **Insert** and arrange it on the canvas.
4. Use the animation tools to set the pace, then click **Play** to preview.
5. Save your editable project or export a presentation player to share.

> External media and embedded websites require a network connection. Website embeds also depend on the target site's embedding policy.

## Save, edit and share

| Output | Purpose |
| :--- | :--- |
| **`.potatcslide` project** | Keep an editable copy of your presentation. Open it in Potatc Slides when you want to make changes. |
| **Exported HTML presentation** | Share a standalone player for your finished presentation. |
| **Print / PDF** | Produce a static copy for reading, printing or distribution. |

## Useful shortcuts

| While editing | Action |
| :--- | :--- |
| `Ctrl + S` | Save the project |
| `Ctrl + Z` / `Ctrl + Y` | Undo / redo |
| `Ctrl + D` | Duplicate selected objects or the current slide |
| `Ctrl + F` | Find and replace |
| `F5` | Start presenting |

| While presenting | Action |
| :--- | :--- |
| `Space` / `→` | Advance to the next animation or slide |
| `←` | Go to the previous slide |
| `Esc` | Exit the presentation |
